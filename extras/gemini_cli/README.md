# Merino for Gemini CLI

Choose `tokyonight-merino-dark.json` or `tokyonight-merino-light.json` and
set its absolute path as `ui.theme` in your Gemini CLI settings:

```json
{
  "ui": {
    "theme": "/absolute/path/to/tokyonight-merino-dark.json"
  }
}
```

You can also register the file's theme definition in `ui.customThemes` and
select its name (`TokyoNight Merino Dark` or `TokyoNight Merino Light`).

See the [Gemini CLI theme documentation](https://geminicli.com/docs/cli/themes/)
for custom-theme settings.
